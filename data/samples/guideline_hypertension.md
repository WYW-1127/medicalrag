# 中国高血压防治指南（样例文档）

本文件为 MedicalRAG 的合成样例数据，用于入库管线开发与冒烟验证，内容为简化编写的医学知识，不可作为真实诊疗依据。

## 1. 定义与分类

高血压是指在未使用降压药物的情况下，非同日 3 次测量诊室血压，收缩压（SBP）≥140mmHg 和/或舒张压（DBP）≥90mmHg。收缩压≥140mmHg 且舒张压<90mmHg 为单纯收缩期高血压。

根据血压升高水平，将高血压分为 1 级、2 级和 3 级。

| 分级 | 收缩压 (mmHg) | 舒张压 (mmHg) |
| --- | --- | --- |
| 1 级 | 140-159 | 或 90-99 |
| 2 级 | 160-179 | 或 100-109 |
| 3 级 | ≥180 | 或 ≥110 |

## 2. 危险因素

高血压的主要危险因素包括高钠低钾饮食、超重与肥胖、过量饮酒、长期精神紧张以及年龄增长。有高血压家族史的个体患病风险显著升高。

## 3. 诊断评估

### 3.1 血压测量

诊室血压测量要求安静休息 5 分钟后坐位测量，使用经校准的上臂式电子血压计。诊断需非同日三次测量均达标，必要时结合家庭自测血压与动态血压监测。

### 3.2 靶器官评估

高血压靶器官损害的评估包括：心电图与超声心动图评估左心室肥厚；尿白蛋白/肌酐比值与血肌酐评估肾损害；眼底检查评估视网膜病变。

## 4. 治疗原则

### 4.1 生活方式干预

所有高血压患者均应进行生活方式干预：减少钠盐摄入（每日食盐<5g）、增加钾摄入、控制体重（BMI<24）、戒烟限酒、每周进行 4-7 次中等强度有氧运动。

### 4.2 药物治疗

常用降压药物包括五大类：钙通道阻滞剂（CCB）、血管紧张素转化酶抑制剂（ACEI）、血管紧张素受体拮抗剂（ARB）、噻嗪类利尿剂和 β 受体阻滞剂。一般患者血压目标值为<140/90mmHg，能耐受者可进一步降至<130/80mmHg。

## 5. 特殊人群

妊娠期高血压患者首选拉贝洛尔、硝苯地平缓释片等药物，禁用 ACEI 与 ARB（有致畸风险）。老年收缩期高血压患者应从小剂量开始，避免体位性低血压。

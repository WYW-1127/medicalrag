## 完整版

### MedicalRAG：心血管专科医学知识问答 Copilot

**项目定位**：个人独立开发的生产级专科医学 RAG 系统。基于权威临床指南与药品说明书构建检索增强问答服务，回答全程可溯源、证据不足即拒答，配套量化评估体系与一键部署。

**项目背景与核心目标**
医学问答场景对幻觉零容忍：大模型直接回答医学问题存在编造剂量、虚构疗法的风险。本项目目标是构建一套"每个结论可溯源到指南原文、缺乏证据时明确拒答"的专科问答系统，并用可复现的量化指标证明检索与安全机制的有效性，而非停留在 Demo 层面。

**核心功能与技术实现**

- **混合检索管线**：Milvus 单库实现稠密（BGE-M3）+ 稀疏（BM25/jieba 中文分词）双路召回，自实现 RRF 与加权融合（未用内置 Ranker，支持消融对比），BGE-reranker-v2-m3 交叉编码器精排，支持科室/文档类型元数据过滤
- **Agentic 检索编排**：基于 LangGraph 构建 9 节点状态机——意图/急症识别、查询改写（指代消解 + 术语归一）、多跳问题分解、Self-RAG 式检索反思（相关性打分不达标则带反馈重写，上限 2 轮）、带引用角标生成、逐句忠实度校验（不通过带问题再生成）、拒答兜底；每个节点独立 Pydantic Schema 可单测
- **医学安全机制**：急症/自伤类问题前置拦截并引导就医；证据不足诚实拒答；全部回答附免责声明与 `[n]` 引用角标（前端点击定位到指南章节与页码）
- **数据管线**：多格式解析器（PDF 字号聚类标题识别/双栏阅读序/表格保全、Markdown、HTML、结构化 JSON/CSV）→ 统一 Section 树 → 结构感知分块（句子边界聚合 + 跨块重叠 + 表格整块保留）→ 向量化；按文档哈希删除重插实现幂等入库
- **工程化**：FastAPI 全异步 + SSE 流式输出（节点事件/增量文本/引用汇总三类事件）；JWT 认证与多轮会话持久化；React 18 + TypeScript 前端（流式 Markdown 渲染、引用溯源卡片、Agentic 检索过程实时时间线）；Docker Compose 一键编排 7 容器；GitHub Actions CI（前后端双 job）；142 个单元/集成测试，ruff + mypy strict 零告警

**项目成果与数据指标**（108 题分层测试集，检索消融 + 中文 LLM-as-Judge）

- 检索质量：消融实验证明重排为核心收益项——Recall@5 从纯 dense 的 0.569 提升至 **0.625**，MRR 从 0.534 提升至 **0.613**；同时发现 RRF 融合对口语化改写型查询召回无增益，形成"收益依赖查询分布"的实证结论
- 安全指标：知识库外问题拒答率 **90%**（20 题），急症类问题拦截率 **100%**（8 题），无一例编造
- 生成质量：知识库内正常回答率 **83.3%**，忠实度与回答相关性（LLM-as-Judge 评审）均达 **0.95**
- 交付质量：非开发者 `docker compose up` + 一条入库命令 10 分钟内获得可用系统；开发过程沉淀 5 篇架构决策记录（ADR）与分阶段实施计划
